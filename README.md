# WB Workbench v1.1.0-dev · 开发版 / 背景校正功能测试

本机运行的 Western blot 图像定量工作台。导入磷酸化蛋白图和对应总蛋白图，复核软件建议的选区，得到可追溯至每个样本、原图和选区的定量表。

## 从 Git 克隆后的首次运行

这是**开发分支**。仓库只包含源码，不含 Python 环境（`.venv/`）、样例图像（`examples/`）和实验数据（`data/`）。稳定版本在 `main` 分支。

需要 macOS 或 Linux、Python 3.12 及以上：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --open
```

开发版固定监听 `http://127.0.0.1:8766`（`main` 分支用 8765）。按 `Ctrl+C` 停止。

- 侧栏「导入 WBTEST 样例」会提示找不到样例图像，这是预期的——请用自己的图像新建实验。
- 本分支新增的背景曲面模型（模式 B）**默认关闭**，需显式预览并应用；方法与局限见 [DEVELOPMENT.md](DEVELOPMENT.md)。
- 软件目前没有删除实验的功能；独立测试目录用 `server.py --data-dir <路径>`。

运行测试（`openpyxl` 仅测试用）：

```sh
.venv/bin/python -m pip install openpyxl
.venv/bin/python -m unittest discover -s tests -v
```

## 启动和保存

在 Finder 中双击本目录的 **启动.command**。开发版仅使用本目录独立 `.venv`，固定 `http://127.0.0.1:8766`，不会复用标准版服务；端口被其他服务占用时退出。关闭浏览器不会停止服务；在启动终端按 `Ctrl+C` 停止。再次启动恢复本目录已保存的实验。标准版保留在相邻 `wb-workbench/`，请勿互相复制 data。

新增背景模型默认关闭；旧实验继续模式 A。方法、限制、验收步骤见 [DEVELOPMENT.md](DEVELOPMENT.md)。归档中的 `STANDARD_RELEASE.md` 记录历史冻结点，标准版恢复请使用标准版源码发布包。

所有图像和计算均在本机完成，没有远程服务或外部字体。导入时保留原文件的完整副本，不改变原文件。

- `data/state.json`：样本、参数、选区、确认状态和操作历史。
- `data/images/`：导入图像及显示预览。
- `data/audit.jsonl`：可读的操作记录。
- `data/derived/`：按原图、方法、参数、极性、区域绑定的派生数组与显示图；原图不变。
- `logs/`、`exports/`：本开发目录的日志和导出副本；`qa/` 为独立验收副本，不属于日常实验数据。
- 备份：停止服务后复制整个 `data/` 目录；恢复时放回同一位置。ZIP 导出用于核对和归档，目前不提供 ZIP 一键导入恢复。

## 从你的样例开始

1. 本次交付已预载「WBTEST · 截图样例」；空数据目录可点击「导入 WBTEST 样例」。软件使用随附的 `PHO.png` 和 `total.png` 副本；左到右是 Ctr1、Ctr2、Ctr3、Trt1、Trt2、Trt3，前三个设为本次实验的对照。
2. 检查两张图上每个样本的条带框和背景框。拖动/缩放选区，或填写原图像素坐标；两张图分别定位，通过样本编号配对。
3. 样例先避开黑色边框再建议选区，所有候选都处于待确认状态。确认每条泳道对应的两张图后才发布图像信号比。修改选区、分析区域、条带极性或替换图像会撤销相关确认。
4. 在结果表逐项查看原始积分、背景、净信号、比值及来源提示。全部指定对照有效后，计算相对本次对照均值的指标。
5. 导出当前实验或合并多个实验。支持 XLSX、CSV，以及含标记 PNG、原文件、分析快照与操作历史的 ZIP。

新实验可设置 1–32 个样本和对照数。手动框出包含目标条带及邻近背景的分析区域，再生成候选选区。候选检测按给定泳道数寻找近似等间距条带；弱信号可能使用等分候选，仍需人工定位。软件不识别蛋白身份或分子量。

## 计算方法

所有坐标和测量使用原图像素。默认模式 A 中，每个条带使用独立的矩形条带框与局部背景框：

- 暗条带：`净信号 = 条带像素数 × 背景均值 − 条带像素和`。
- 亮条带：`净信号 = 条带像素和 − 条带像素数 × 背景均值`。
- 样本图像信号比：`R = P净信号 / total净信号`。
- 相对指标：`R / 本次实验所有指定对照R的算术均值`。

假设背景框能代表条带区域内近似恒定的背景。背景框应避开其他条带、边框和污点。依据 [ImageJ 测量定义](https://imagej.net/ij/docs/menus/analyze.html)，原始积分是选区内像素之和；这里的局部背景扣除是透明、可复核的第一版方法。

模式 B 必须先预览，再明确点击「应用于定量」：整块分析区域拟合稳健二次背景曲面 B；暗条带净信号为条带 ROI 内 `Σ(B−I)`，亮条带为 `Σ(I−B)`。保持原始强度单位及负值，旧背景框不再参与扣除。两模式互斥；恢复 A 后须重新确认。p 与 total 分别设置。

条带/背景重叠、不同样本条带重叠、背景覆盖其他条带、越界或非正净信号均需要复核。软件保留可计算的原始值与异常说明，不截断为零。仅处于浮点计算舍入误差量级的微小净值也暂不用于比值；这不是生物学检测阈值。两张图未全部确认时比值留空；没有对照或任一指定对照未有效确认时相对值留空。空白不代表零，软件不借用其他实验的对照。

XLSX 包含「定量结果」「测量明细」「方法与来源」。积分扣背景、比值及相对指标带可检查的公式与导出时的缓存结果。修改导出的表格不会回写软件。CSV 是同一时点的数值快照；完整 ZIP 同时保存原图 SHA-256、选区和历史。

## 图像支持及解释边界

- 支持单张 TIFF/TIF、PNG、JPEG/JPG、BMP，含 8 位灰度/RGB 和 16 位单通道整数图像。16 位预览可拉伸显示，计算保留原值；显示和原值的区别见 [ImageJ 文档](https://imagej.net/ij/docs/guide/146-28.html)。
- RGB 使用固定 `0.299R + 0.587G + 0.114B` 转灰度并记录提示，不应用 ICC 或伽马校正。显示缩放不改变测量。
- 单图上限 45 MB、4,000 万像素；第一版明确拒绝多页 TIFF、16 位多通道 TIFF/PNG、透明图像、浮点图像和二值图像。
- PNG 后缀不能证明图像来自仪器原始输出。你提供的两张样例均为带 Screenshot 元数据的 8 位图像，有黑色边框。软件提示其来源限制，并允许复核测量。
- 灰度端点计数仅描述当前文件，不能证明原始采集饱和，也不能证明线性范围。JPEG、截图或未知处理历史的损失不能由软件恢复。
- p 与 total 来自不同膜，且缺少每块膜额外的上样/转膜参照。输出因此命名为**图像信号比**，不能解释为绝对磷酸化比例；人工确认只确认选区，不验证跨膜可比性或实验线性。参见 [LI-COR 的归一化说明](https://www.licorbio.com/applications/quantitative-western-blots/normalization)。
- 第一版不做显著性检验、组间统计图或自动生物学结论。

## 开发和迁移

实现为 Python 标准库 HTTP 服务、NumPy/Pillow 计算和原生浏览器界面，不依赖 Node.js、MCP 或云端部署。仅监听 `127.0.0.1`。

若迁移到没有现成运行环境的电脑，可自行创建局部虚拟环境：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --open
```

开发测试：`python3 -m unittest discover -s tests -v`。部分导出核对测试使用 openpyxl，仅为测试依赖；应用导出 XLSX 本身使用标准库。测试检查数值和软件流程，并不构成仪器采集或生物学定量验证。

更新源码前备份 `data/`。卸载本软件可移走本目录；要保留实验请先保留 `data/` 和导出归档。软件未写入全局技能目录或项目规范。
